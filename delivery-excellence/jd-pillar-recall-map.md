## Practice Protocol (apply these three, don't just read them)

### 1. Inverted table — active recall drill
Cover the "Artifacts & Key Acronyms" line for each pillar. Read only the pillar name and Ctrl+F Search Terms. Say the artifact names and mnemonic from memory before revealing. If you can't produce the mnemonic chain unprompted, that pillar needs another rehearsal pass before the interview — don't just re-read it, retest it tomorrow.

### 2. CGP cross-link
Pillars 3 and 4 are flagged "Partial gap" here — that's not duplicate tracking, it's the same open work as the paused **CGP (Capacity Governance & Productivity)** task. Resolve CGP once, and both pillar rows close simultaneously. Don't let this file and CGP drift into two separate half-finished efforts.

### 3. Cold-retest sequencing
Next full retest should run in **pillar order (1→6)**, not story order (A→B→C→D). An interviewer's question bank is built off the JD, not off your story structure — rehearsing in pillar order is the closer simulation of how questions will actually arrive, and it forces you to practice the cross-story jumps (e.g., Pillar 1 pulling from both Story A and Story C) rather than reciting one story start to finish.
